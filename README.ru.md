# Cigaro

**От первого семени до последней затяжки.**

Плагин для Paper-серверов о выращивании табака, ремесле и ролевой игре.

[English](README.md) · [Русский](README.ru.md) · [Скачать бету](https://github.com/TheSpecialChoosenOne/Cigaro/releases/tag/v1.1.0) · [API аддонов](docs/ADDON_API.md)

</div>

> **Бета:** в Cigaro уже можно играть, но длительная работа с несколькими игроками и совместимость с другими плагинами ещё требуют более широкой проверки. Перед установкой и обновлением сделайте резервную копию мира и данных плагина.

## Создай свою историю

Выращивай разные сорта табака, учись их обрабатывать и создавай изделия, которыми можно поделиться. Экспериментируй с сушкой, нарезкой, вкусами и купажами или построй автоматизированную мастерскую.

- **Выращивай и исследуй.** Обычные семена можно найти в траве, древние — во время археологии и исследований, а караванный табак иногда продаёт странствующий торговец.
- **Создавай и экспериментируй.** Суши и нарезай листья, смешивай сорта, добавляй вкусы и создавай сигареты, сигары, трубки или кальян. Твои решения влияют на готовое изделие.
- **Построй мастерскую.** Используй специальные станции и автоматизацию с собственными моделями и интерфейсами из ресурспака.
- **Добавь персонажу историю.** Курение влияет на личную статистику, толерантность и зависимость. Выученные привычки могут иногда напоминать о себе в подходящей ситуации; никотиновый пластырь временно подавляет симптомы ломки.
- **Настрой под свой сервер.** Изменяй эффекты, шансы выпадения и другие механики, а также редактируй русские и английские языковые файлы.

## Требования

| | |
|---|---|
| Сервер | Paper **26.3** |
| Java | **25** |
| Клиент | Minecraft **26.3** с ресурспаком Cigaro |
| Статус | Бета; API аддонов экспериментальный |

Поддержка других серверных ядер и версий Minecraft не проверена.

## Установка

1. Скачайте `Cigaro-1.1.0.jar` и `Cigaro-ResourcePack-1.1.0.zip` со [страницы релиза](https://github.com/TheSpecialChoosenOne/Cigaro/releases/tag/v1.1.0).
2. Поместите JAR в папку `plugins` сервера и перезапустите сервер.
3. Установите ZIP как ресурспак клиента или настройте его раздачу с сервера. Ресурспак нужен для пользовательских моделей, текстур и интерфейсов.
4. При необходимости измените `plugins/Cigaro/config.yml` и языковые файлы в `plugins/Cigaro/lang/`. По умолчанию выбран английский язык; для русского укажите `language: "ru_ru"`.

Если сервер уже использует другой ресурспак, проверьте пересекающиеся определения предметов и шрифты и при необходимости объедините их. Раздача нескольких паков сама по себе не устраняет конфликты.

## Первые шаги

1. Ломайте траву в поисках семян табака. Разные сорта связаны с разными биомами.
2. Посадите семена на грядку и соберите выросшее растение.
3. Скрафтите сушилку, высушите листья и подготовьте табак на столе для нарезки.
4. Попробуйте разные вкусы и купажи, затем создайте первые изделия на скручивающей машине.

Экспериментируйте и находите сочетания, подходящие вашему персонажу. Помните, что курение может привести к зависимости и ломке: никотиновый пластырь временно подавляет симптомы, но не избавляет от самой зависимости.

## Команды

| Команда | Назначение |
|---|---|
| `/cigaro` | Показать справку по командам |
| `/cigaro stats` | Посмотреть свою статистику курения |
| `/cigaro achievements` | Посмотреть свои достижения |
| `/cigaro top` | Открыть рейтинг курильщиков |
| `/cigaro give` | Посмотреть предметы и формат выдачи; для администратора |
| `/cigaro debug` | Показать инструменты отладки; для администратора |
| `/cigaro reload` | Перезагрузить конфигурацию и языковые файлы; для администратора |
| `/cigaro analytics` | Посмотреть аналитику плагина; для администратора |

Используйте автодополнение для выбора предметов и параметров. Право `cigaro.admin` по умолчанию есть у операторов сервера. `cigaro.use` по умолчанию доступно всем игрокам и проверяется только в некоторых механиках; не стоит рассчитывать, что его снятие полностью запретит взаимодействие с плагином.

## Настройки и данные

В конфигурации можно изменить шансы выпадения семян и ингредиентов, сушку, скручивание, эффекты, зависимость, толерантность и медицинские настройки. После изменения перезапустите сервер или используйте `/cigaro reload`. Перед обновлением и переносом данных остановите сервер и сохраните резервные копии мира и всей папки `plugins/Cigaro/`.

## Разработчикам

В [руководстве по API](docs/ADDON_API.md) и [примере аддона](examples/addon/) показаны регистрация типов и работа с событиями. API **экспериментальный**: совместимость между версиями не гарантируется, а удаление аддона, чьё содержимое уже существует в мире, не поддерживается.

Сборка плагина и ресурспака с Java 25:

```bash
./gradlew build
```

JAR появится в `build/libs/`, ZIP ресурспака — в `build/distributions/`.
