# Cigaro Effect Tester — datapack

Отдельный датапак для быстрого теста post-эффектов из `Cigaro_Shaders_26_3_RP.zip`.

## Команды

```mcfunction
/ce puff 5
/ce killer_trip 8
/ce remove puff
```

- `/ce <effect> [seconds]` — включает `cigaro:<effect>`, держит его указанное число секунд (по умолчанию 5), затем включает `cigaro:<effect>_out` и через 8 секунд снимает его.
- `/ce remove <effect>` — мгновенно снимает и in-, и out-вариант.
- `/ce remove` или `/ce remove all` — снимает все эффекты сразу.

Доступные эффекты: `puff`, `mint_chill`, `spice_heat`, `shadow_noir`, `withdrawal`, `killer_trip`.

`shadow_noir` — legacy ID: визуально это уже Berry / Sweet Capsule (сладкая капсула), а не ч/б нуар. ID сохранён, чтобы не ломать существующие вызовы и будущую интеграцию.

## Tab completion

`/ce` регистрирует отдельный Paper-плагин `CeTester` (`tools/ce-tester-plugin`):

- Tab после `/ce` — список эффектов и `remove`;
- Tab после `/ce <effect>` — подсказки времени: `1`, `2`, `3`, `5`, `10`, `15`, `30`, `60`;
- Tab после `/ce remove` — список эффектов;
- в `/ce` без аргументов — кликабельные названия эффектов и tooltip'ы.

Алиас `ce` из `run/commands.yml` удалён, чтобы не конфликтовать с плагином. `CeTester` не зависит от Cigaro и только вызывает функции датапака.

## Важно

Чистый ванильный датапак не умеет регистрировать новые root-команды и не умеет делать Tab completion для них. Без плагина тот же вызов работает так:

```mcfunction
/function ce:dispatch {a:puff,b:5}
/function ce:dispatch {a:remove,b:puff}
```

## Таймеры

- `ce_<effect>_p` — фаза: `0` idle, `1` in/hold, `2` out.
- `ce_<effect>_t` — тики до конца текущей фазы.
- Время пользователя переводится в тики через `#20` (`20` тиков/сек).
- Fade-out оставляется включённым на `#out` = `160` тиков (8 секунд), чтобы шейдер успел дойти до нуля на медленном клиенте. Это не влияет на картинку после затухания: out-шейдер при нулевой интенсивности просто копирует кадр.
- `#duration` — последняя длительность в секундах; по умолчанию `5`. Её выставляет `start_<effect>_args`; ручной вызов `ce:start_<effect>` использует это же значение.
- `/ce` без аргументов показывает подсказку; неизвестный эффект — короткое сообщение с предложением нажать Tab.

## Установка

Датапак: скопировать папку `cigaro_effect_tester` в `<world>/datapacks/` или включить
`cigaro_effect_tester.zip` через `/datapack enable`.

Плагин:

```bash
./gradlew -p tools/ce-tester-plugin build
cp tools/ce-tester-plugin/build/libs/CeTester-1.0.0.jar run/plugins/
```

Право `cetester.use` по умолчанию выдано операторам. После установки плагина нужен рестарт сервера.

## Проверено

- `ce puff 4`: фаза `1` — 4.0 с, затем фаза `2` — 8.0 с, затем `0`; суммарно 12.0 с.
- `/ce remove puff` снимает обе фазы сразу.
- Пустой/неизвестный аргумент не вызывает ошибок в чате.
- Ошибок загрузки функций и macro-инстанцирования нет.
- Шейдерный пак пересобран под новый `cigaro_fx.fsh`; все 12 эффектов добавляются/снимаются без ошибок.
- После рестарта с `CeTester 1.0.0` команда `/ce` зарегистрирована, `help ce` показывает оба варианта синтаксиса; `/ce killer_trip 1` и `/ce shadow_noir 3` выполнены с клиента без ошибок плагина.
